# 实验方法与判定规则

本轮以 Qwen2.5-1.5B-Instruct 固定 snapshot `989aa7980e4cf806f80c7fef2b1adb7bc71aa306` 为学生和 baseline。研究从 2026-09-09 15:16:40 UTC 开始，计算硬截止为次日同一时间。初期仅使用GPU1和GPU3；用户明确允许三张卡后，06:27:57 UTC登记修订并增加GPU2，最多同时三张。资源日志每30秒记录一次，原数据与统计方案保持冻结。

## 复用与新实验的界限

前轮已验证的 mask、causal shift、token-mean accumulation、保存/加载和真实模型 attention 算术审计直接引用原始产物。本轮只对改动的路径及实际推理协议作必要验证，不重复原始 raw 数据的 rank/full/DFT/八轮搜索。前轮的 1175 对 raw/self 目标、三个 seed checkpoint、MATH dev500 及确认统计均保留原目录不修改。

现有两批 MATH 确认题已经被前轮使用，本轮只能称复用验证。新的 OOD 集在选模前下载并固定，未参与训练目标生成或开发期选择。Minerva、OlympiadBench、SVAMP 作为三个等权数学任务，AMC23 因题量小仅作辅助。它们的结果不代表非数学领域的一般能力。

## 监督目标构造

学生对原2000题各生成8个解答：temperature0.7、top_p0.95、seed20260909；Qwen2.5-7B-Instruct 对同题各生成1个 greedy 解答。两者都不看到参考答案，仅在生成后以参考最终答案筛选。保留原始输出；实际训练候选要求最后完整 boxed 可验证、正常停止、无解答图形源码，且完整 chat prompt+completion+EOS 不超过2048 token。前轮逐条排除的五道题和本轮审查发现的错误解答另行记录排除。

每题从合格候选中按固定随机种子选择一个。学生与教师的所有可用题集用于探索，同题交集用于比较目标来源；学生原先 greedy 答错的题与仅被旧长度/质量过滤排除的题分别标识，不能混称“原先不会的题”。另外构造每题4个候选槽位的多解答数据与单解答重复数据，二者问题顺序和样本数完全一致，用以区分解答多样性和曝光次数。

最终答案正确不是完整过程认证。逐条抽查的抽样方式、解答全文、判断和排除清单都必须报告；不能把条件抽查的错误比例当总体错误率。

## 训练

默认 QKVO LoRA r16、alpha16、dropout0；先在 FP32 基座上初始化 A/B，再把冻结基座转为 BF16，A/B 与 AdamW 状态保持 FP32。不同对照的同一 seed 初始化过程保持一致。AdamW fused，weight_decay0.01，clip1，microbatch4，有效 batch16。默认明确启用 SDPA math，关闭 flash、cuDNN 和 efficient SDPA；eager 只用于指定匹配消融。全部训练前后检查梯度有限。

学习率按样本曝光计，前64条 warmup，之后8轮 horizon cosine；第一步实际 LR0。`--stop` 控制主动停止轮数，不改变 horizon。每轮 checkpoint 保存 A/B、配置、tokenizer，训练记录保存题目顺序、有效监督 token、LR、梯度范数、CE。主要独立seed均从base重训。后加的resume分支保存并恢复optimizer与RNG，已用于teacher seed43从epoch4继续至epoch8；它共享原训练历史，不作为独立seed。

主要目标为有效 batch 的 completion token-mean CE。辅助 example-mean 先对每题的有效 completion token 求均值，再对有效 batch 的题求均值；这是目标选择而非修复已知代码 bug。所有预算同时报告 optimizer steps、问题曝光与 token 曝光；不同长度目标的同题/同步数比较不等于 token 或 FLOP 匹配。

## 生成与评分

固定 BF16 未合并 LoRA 的 vLLM 推理，TRITON attention，batch-invariant，关闭 prefix cache 和 async scheduling，greedy、max_new_tokens2048、max_model_len4096、max_num_seqs512，每次提交最多500题。显存比例影响资源预留，另用 base 重复与非零历史 adapter 核对实际输出。确认和 baseline 使用相同推理路径，不混合 FP32 历史分数。

主评分复用 math-verify 完整文本答案提取；最后完整 boxed 评分作为敏感性检查。保存每题文本、停止原因、token 数和 hash；抽查真实数学错误以及格式/截断因素。Minerva 的近似数值和带单位答案、Olympiad 的表达式答案需额外审查，不能把本地统一评分冒充完全复现每个 benchmark 的官方评测器。

## 推断与停止条件

开发期先按 dev500 生成表现筛选候选；在19:32 UTC、任何本轮1500题结果出现前记录的方案修订后，历史复用MATH1500也作为开发验证辅助选择。它不属于新鲜确认集。报告所有已完成分支和多重比较敏感性。开发稳定性保留seed43/44/45。根据最终seed精度修订，冻结主配方目标文件、配置、checkpoint选择及seed43/44/45/46/47的全部权重后才使用新OOD确认结果。主要能力提升要求五个seed均高于baseline，且配对题目平均效应的95%区间排除零；跨数学任务的提升另看预设等权平均和每个任务结果，不以某一涨分任务代替全部证据。

每道题在不同seed中的回答按同一题配对，不能把重复回答算成多道独立题。报告逐 seed 的得失、McNemar、按题 bootstrap，以及共享题目样本的交叉 seed/题目 bootstrap。开发家族3个seed、最终主配方5个seed，交叉bootstrap用于反映这组有限seed与题目的不确定性，不能保证所有可能训练seed。最终判定要求题目及seed/题目两种区间的下界都严格大于零。

因果解释需要匹配干预、重复方向和机制支持。改变目标构造这一整体流程不等于已经隔离了长度、风格、内容和质量的独立贡献。有限阴性实验最多支持指定条件下未发现收益，不能证明 LoRA 普遍不能进行 SFT。若到24小时仍未达到证据标准，须明确报告未解决，而不制造二选一结论。

## 审查者与证据强度

本次解答逐条审查由研究助手完成，并保留具体推导或可核验的反例；不是独立人类数学专家标注。后续若使用缓存模型作批量过程判断，该输出仅是弱标签，需要与明确的错误案例及逐条审查交叉核查。两种审查都不能替代数学过程证明或全面的专家审核。

## 最终输出前的Minerva数值评分修复

在任何本轮完整MATH/OOD输出前，发现通用LaTeX解析会将58条科学计数法gold解释成含欧拉常数的表达式，且极小非零值比较存在绝对舍入误接受。所有数据和生成路径保留；191道Minerva数值题改用独立安全解析、最后完整boxed、有限实数、相对1e-4与绝对0容差。81符号题沿用相应原始或严格评分。191道数值参考的正确表示/乘2错误值测试与完整scorer的正负合成集成测试通过；另固定1%/5%及旧评分敏感性，均不取代主规则。

这项修复只改变最终分析中的Minerva数值向量，原始预测中的legacy评分不覆盖。`scoring_minerva_numeric_corrected.json`记录修正向量、逐题数值解析、所有warning及源哈希。两种最终分析的Minerva数值题均用该分支，不能把raw变量名误读为全部仍用旧评分。具体方案见`audits/minerva_numeric_scoring_amendment.json`。

额外前置负例检查：开发435个实数gold的乘2/零加1均被拒绝；完整MATH4387个仅index2854接受了错误2/2004!。完整5000主评分不改，补充固定4999题及合并保守重叠候选的4996题敏感性。这些检查是具体反例测试，不能证明评分器普遍正确。

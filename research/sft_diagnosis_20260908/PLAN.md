# SFT 诊断研究计划

目标是区分具体实验方案失效、LoRA 的容量/优化限制和 SFT 目标与生成准确率不一致。研究不预设能够找到正收益配置。历史结果仅作为历史证据，新结论必须注明协议、样本量及适用范围。

1. 保存当前代码、依赖和历史结果来源；重算逐题配对统计，审计数据重叠、监督掩码、梯度累积和保存加载。
2. 在相同 2,000 道 MATH 原始训练题、数据顺序、token-mean completion CE、batch16、AdamW、125-step cosine horizon、4-step warmup 下，比较 QKVO LoRA r16、all-linear LoRA r16/r64、相同线性矩阵的无低秩约束更新、全参数 SFT。LoRA LR 覆盖 1e-5/1e-4，全参数 LR 覆盖 1e-6/1e-5；不是假设同 LR 公平。LoRA 固定 alpha16，rank 对照保持 alpha 不变；dropout0 排除额外随机正则。seed43，保存 step25/125，明确早停只见400题。
3. 所有新训练使用 FP32 参数及 FP32 AdamW 状态、统一 BF16 autocast 前向/反向、eager attention。所有新模型合并为 FP32 完整权重后，以统一 FP32 vLLM/TRITON_ATTN 推理，避免 LoRA kernel 和 BF16 权重舍入成为方法间混杂；先做可运行性与跨进程重复检查。若不支持则在实验前记录修订，不混合协议。
4. 初筛只使用既有 MATH dev500 的生成正确率；base 参与选模。分别选最佳 LoRA 和最佳 full SFT（平局选择更早 checkpoint，再更小 LR）。step125 为预先指定的完整曝光对照，step25 为轨迹/候选。最多对两种选定配置以 seed44/45 复验。未达到显著收益同样报告，不把最优点当确定进步。
5. 在选模之后固定配置，评估 MATH official test 中排除历史已评分题后的新题；若不足则完整说明无法获得全新 holdout。GSM8K 历史上已全量评测，全部视为复用诊断集，不声称新 OOD test。仅选中配置在这些题集上确认，不用确认集继续调参。
6. 保存逐题输出、所有命令、权重与数据哈希、实际曝光、训练损失和梯度范数。配对 bootstrap 95% CI 与 exact McNemar，报告多比较和 seed 不确定性；复核错误案例、分层变化、解析失败和长度截断。
7. 查阅原始 LoRA/QLoRA、LoRA 对比 full SFT 研究及官方训练/推理文档。区分外部研究和本机因果证据，最终交付中文研究报告、可复现脚本及数据表。

资源：使用低负载共享 GPU 的剩余容量，不终止原有任务。先完成一轮有明确边界的实验；扩展只为解决实质性不确定性。代码改动与实验产物全部放本目录，历史代码和结果不覆盖。

判定边界：full SFT 同样下降，说明移除低秩约束不足以修复当前配置，但不证明 LoRA 等价于 full；LoRA 改善则构成本任务下可用性的直接证据；未显著差异不视为等效。此轮没有跨模型大规模验证，不能证明任何方法普遍优劣。

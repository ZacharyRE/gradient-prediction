# SFT 因果诊断完成标准

状态：进行中。上一轮报告属于阶段性排查，不能作为已完成根因定位。

必须完成以下至少一项有充分证据支持的论证，才能结束研究：

1. 定位当前实验 setup 的具体问题，指出代码或配置的具体位置，给出可执行修改，并通过受控的修正前后对照、重复训练及独立确认，支持该问题导致退化且修正有效。
2. 在明确限定的模型、数据、优化方案、训练曝光及搜索范围内，通过足够公平、充分优化的对照证明 LoRA SFT 不适用。不得把有限范围失败推广成所有 LoRA 或所有 SFT 均无效；仅仅没有搜索到收益、置信区间跨零、或 full SFT 同样失败，均不足以达标。

在两项均未达标时继续研究，不把执行数量、loss下降、排除若干问题或观察到退化当作完成。不能为了强行满足二选一而编造原因。

本阶段优先延长已经下降的训练轨迹，并进行有效 batch size × learning rate 组合。以相同训练曝光比较不同 batch，区分 optimizer steps 与 epoch；保留完整训练状态用于可靠续训。持续检查空闲 GPU，不终止其他任务。

# 独立确认的预先标准

目前还没有冻结修复方案，1500 题确认集未评测。先在既有 dev500 上完成因果干预，才确定一个主要配置及比较对象。所有已经尝试过的失败分支仍保留。

主要比较必须是同一基座、问题集、初始化 seed、采样顺序和训练预算下，修复 vs 对应的未修复设置。不能只拿最差历史结果作对照。重复训练固定三个 seed：43、44、45；在每个 seed 内作匹配干预。新的确认题不用于再选 LR、checkpoint、数据过滤规则或 seed。

如果目标是阻止当前大幅退化，确认要求同时具备：

1. 修复对未修复配置有明确的配对准确率收益，独立题集的 95% CI 排除零，三个训练 seed 的差异方向一致。
2. 修复相对 base 的配对区间排除超过 2 个百分点的退化（事先采用的实用非劣界限，并不是精确等价证明，也不代表用户已认可任意 2 pp 损失）。若 CI 仍允许更大退化，不称为修复完成。
3. 有真实学习与非平凡更新的证据：相同正常 LR 与充分训练曝光，保留权重变化、目标 loss、训练行为和输出变化，不能靠零 LR、零步或几乎未改动的模型达标。必要时增加原始目标的更新量对照，区分方向与更新幅度。
4. 模型加载、计算路径、评分和数据隔离有实测验证；代码和数据修改可复现。

若修复只能保留 base 能力而未确认正收益，最终只能表述为找到了造成退化的 setup 因素及其缓解方式，不能称为已提高数学能力。若要宣称提高数学能力，还要求相对 base 的独立配对收益 CI 排除零。

以上标准不能替代 [OBJECTIVE.md](OBJECTIVE.md) 的因果论证要求。统计显著但存在未控制的主要混杂、或者只是完成了搜索，均不允许结束研究。若尚未出现符合条件的候选方案，继续研究而不消费确认集。
